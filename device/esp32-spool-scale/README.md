# ESP32 spool scale — 4 катушки

По одному тензодатчику и HX711 на катушку. ESP32 отдаёт вес по HTTP, мост читает
`GET /spools/weights`, плагин Orca показывает его в панели IFS/AFC и синхронизирует
остаток со Spoolman.

## Электрика

| Канал | HX711 DT | HX711 SCK |
|---|---|---|
| lane1 | GPIO16 | GPIO17 |
| lane2 | GPIO18 | GPIO19 |
| lane3 | GPIO21 | GPIO22 |
| lane4 | GPIO25 | GPIO26 |

- Все `VCC` HX711 → **3.3V ESP32**, все `GND` → общая земля.
- Если модуль HX711 питается от 5V — DT нужно пропустить через логический level shifter до 3.3V.
- Тензодатчик (4 провода): красный `E+`, чёрный `E-`, зелёный `S+`, белый `S-` → соответствующие контакты HX711.

Пины можно поменять в прошивке (массив `lanes`).

## HTTP API устройства

- `GET /weight` → `{"lanes":[{"lane":1,"grams":812.3,"stable":true}, ...]}`
- `POST /tare?lane=1` — тарировка пустого держателя.
- `POST /calibrate?lane=1&known=1000` — калибровка эталонным грузом.

Калибровки и тара сохраняются в `Preferences` ESP32.

## Механика

Каждая катушка sits на отдельной консольной балке:

```
[рама принтера] ===[тензодатчик]=====[ось + подшипник 608]====(катушка)
```

- Тензодатчик жёстко крепится одним концом к раме/стойке.
- На свободном конце — ось катушки на подшипнике 608ZZ (8×22×7 мм).
- Нагрузка должна быть **вертикальной**, без боковых усилий.
- Нити от IFS не должны тянуть за датчик — оставьте свободный ход и направляющую.

### Печатные детали (`model/spool_scale_bracket.scad`)

Параметрическая модель OpenSCAD:
- `arm_length` — длина консоли (по умолчанию 90 мм);
- `cell_l`, `cell_w`, `cell_t` — габариты тензодатчика (по умолчанию 80×12.7×6 мм);
- `axle_d` — диаметр оси под 608 (8 мм);
- `m3` — отверстия под M3;
- `clearance` — зазор под посадку датчика (0.3 мм).

Печать: PETG/ASA, слой 0.2 мм, 5–6 стенок, 50–70% infill. Крепление датчика —
так, чтобы слои не расходились под нагрузкой (расположите балку горизонтально).
Используйте heat-set вставки M3, не откручивайте датчик от балки при калибровке.

## Калибровка

1. Соберите балку, установите пустую ось.
2. `POST /tare?lane=N` для каждого канала.
3. Положите эталон (например 1000 г) на ось.
4. `POST /calibrate?lane=N&known=1000`.
5. Проверьте `GET /weight` — значения должны совпадать с эталоном ±1–2 г.

## Интеграция

В настройках плагина Orca (⚙) задай `Адрес весов` = `http://<ip_esp32>`.
Затем в панели IFS/AFC нажми **«Обновить слоты»** — появится реальный вес.
Кнопка **«Синхронизировать Spoolman»** запишет остаток в Spoolman через API.

## Зависимости Arduino

- `HX711` (Arduino Library Manager)
- `ArduinoJson` v6
- ESP32 board package
